# Web Development Resource Master List

Welcome to the our resource hub! Here you will find a curated collection of interactive games, documentation, and tools to help you master HTML, CSS, Git, and JavaScript.

## HTML

* [**MDN HTML**](https://developer.mozilla.org/en-US/docs/Web/HTML): The ultimate reference guide to keep open while coding.

* [**web.dev Learn HTML**](https://web.dev/learn/html): Structured, short learning modules.

* [**web.dev Learn Accessibility**](https://web.dev/learn/accessibility): Essential accessibility basics.

* [**W3C Markup Validator**](https://validator.w3.org/): Tool to check your markup for errors.

## CSS

* [**MDN CSS**](https://developer.mozilla.org/en-US/docs/Web/CSS): Comprehensive reference and guides.

* [**web.dev Learn CSS**](https://web.dev/learn/css): Covers the box model, the cascade, and layout.

* [**CSS Diner**](https://flukeout.github.io/): Learn CSS selectors by playing a game.

* [**Flexbox Froggy**](https://flexboxfroggy.com/): Master CSS Flexbox through a fun game.

* [**CSS Grid Garden**](https://cssgridgarden.com/): Learn CSS Grid by growing a digital garden.

* **CSS-Tricks**: The ultimate guides for [Flexbox](https://css-tricks.com/snippets/css/a-guide-to-flexbox/) and [Grid](https://css-tricks.com/snippets/css/complete-guide-grid/).

* **Typography & Colors**: Resources for [Google Fonts](https://fonts.google.com/) and [Coolors](https://coolors.co/) palettes.

* [**Frontend Mentor**](https://www.frontendmentor.io/): Real design challenges to recreate and practice your skills.

## Git

* [**Oh My Git!**](https://ohmygit.org/): A game that teaches Git visually.

* [**Learn Git Branching**](https://learngitbranching.js.org/): Interactive branching sandbox.

* [**Pro Git book**](https://git-scm.com/book/en/v2): Free, thorough, and readable guide to Git.

* [**Git documentation**](https://git-scm.com/docs): Comprehensive reference for every command.

* [**GitHub Skills**](https://skills.github.com/): Short, hands-on courses right inside GitHub.

* [**Visualizing Git**](https://git-school.github.io/visualizing-git/): See commits and branches update as you type commands.

## JavaScript

* [**javascript.info**](https://javascript.info/): Clear, modern tutorial packed with exercises.

* [**MDN JavaScript**](https://developer.mozilla.org/en-US/docs/Web/JavaScript): The standard reference and guide.

* [**Eloquent JavaScript**](https://eloquentjavascript.net/): A comprehensive, free book for deeper learning.

* [**Exercism JavaScript track**](https://exercism.org/tracks/javascript): Practice exercises with community feedback.

* [**JavaScript30**](https://javascript30.com/): Build 30 small projects using plain JS (no frameworks).

* **Stretch Quest APIs**: Free APIs from [Open-Meteo](https://open-meteo.com/) and [PokeAPI](https://pokeapi.co/) for building projects.

## Tools and Deployment

* [**VS Code**](https://code.visualstudio.com/): Recommended editor, specifically with the *Live Server* extension.

* [**Chrome DevTools docs**](https://developer.chrome.com/docs/devtools): Learn how to debug and inspect your code in the browser.

* [**GitHub Pages**](https://pages.github.com/): Free hosting solution for your capstone projects.

* [**freeCodeCamp**](https://www.freecodecamp.org/): Free, full-length courses for anyone who wants to dive deeper.
